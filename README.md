# Genius Developers

A premium AI-focused developer portfolio built with Next.js, MongoDB, and modern UI architecture.

🌐 Live Site: https://geniusdevelopers.space

---

## ✨ Features

- Modern responsive portfolio UI
- Dynamic content powered by MongoDB
- AI-focused developer branding
- SEO optimized metadata
- Project showcase system
- Skills & services management
- Resume integration
- Dark / light theme support
- Optimized performance with ISR

---

## 🛠 Tech Stack

### Frontend
- Next.js 15
- React
- TypeScript
- TailwindCSS
- shadcn/ui

### Backend
- MongoDB
- Mongoose
- API routes

### Deployment
- Vercel

---

## 🚀 Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```

---

## 📁 Project Structure

```bash
app/              # Next.js app router
components/       # UI components
lib/              # Utilities & database
models/           # MongoDB models
public/           # Static assets
```
